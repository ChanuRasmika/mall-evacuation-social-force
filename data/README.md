# Data

No external data are used. Every input is synthetic: the floor geometry is assumed (notebook Section 2.1), and the model parameters and input distributions come from the published Social Force Model papers [1], [2] (see [REFERENCES.md](../REFERENCES.md)). The bottleneck-flow values used in check V6 are copied by hand from Table 2 of [7] and are written directly in the notebook.

## `results_main.csv`

960 rows: $N \in \{100, 200, 300, 400, 500, 600, 700, 800\}$ × 6 exit widths per $N$ × 20 seeds (1000–1019).

| Column | Unit | Meaning |
|---|---|---|
| `N` | people | crowd size |
| `w` | m | width of each of the two exits |
| `seed` | — | random seed of the replication; the same seed gives the same starting crowd for every width |
| `dt` | s | time step used (0.005 for N ≤ 400, 0.0025 above; it would be halved again if a run failed a per-step check, which none did) |
| `T_evac` | s | time the last person left; empty if the run had not cleared by 360 s |
| `T_90` | s | time 90 % of the crowd had left; empty if fewer than 90 % left |
| `cleared` | — | `True` if everyone left within 360 s |
| `n_left` | people | people still inside at the end of the run |
| `J_s` | m⁻¹ s⁻¹ | specific flow between 20 % and 80 % evacuated (empty if 80 % was not reached) |
| `peak_density` | m⁻² | highest density in the 2 m half-disc inside an exit |
| `wall_s` | s | compute time of the run (depends on the machine) |

To regenerate the file, set `QUICK_MODE = False` in the notebook's first code cell and run all cells. The runs are spread over all CPU cores, which takes about 25 minutes on a 10-core laptop.

## `results_blocked.csv`

360 rows: $N \in \{100, 200, 300\}$ × $w \in \{1.2, 1.5, 2.0\}$ m × 20 seeds (1000–1019) × two configurations (`exits` = `two` or `one (east blocked)`). Runs stop at 600 s. Columns as in `results_main.csv`, plus `n_west` / `n_east` (people out through each exit) and `peak_density_west` / `peak_density_east` (highest density in the 2 m half-disc inside each exit, m⁻²).

## `results_sensitivity.csv`

140 rows at $N = 600$, $w = 1.25$ m, 20 seeds each: the reference configuration (`factor` = `reference`) and one input changed at a time (`factor` = `v0_mean`, `tau` or `a_rep`, with the value in `level`; m/s, s and N respectively). Runs stop at 600 s. Other columns as in `results_main.csv`.
